# Data licences

No production dataset is distributed in this repository or its current public
technical preview.

The entries in [`data/source-ledger.json`](data/source-ledger.json) are
illustrative fixtures. They use `example.local` URLs, placeholder checksums and
fictional publishers. Their licence identifiers exercise the application’s
metadata contract; they do not grant rights and must not be treated as source
attribution or proof of licence review.

| Fixture | Licence identifier under test | Required attribution |
| --- | --- | --- |
| Example Provincial Harvest Record | `ogl-canada-2.0` | None established; fictional fixture only |
| Example Annual Tree Cover Change | `ogl-canada-2.0` | None established; fictional fixture only |
| Example Mature Forest Estimate | `cc-by-4.0-quebec` | None established; fictional fixture only |

Before any real dataset is ingested or redistributed, this file and the source
ledger must record its exact licence version, authoritative licence URL,
required attribution string, redistribution conditions and legal-review
status. The repository’s code licence does not apply to third-party data.
