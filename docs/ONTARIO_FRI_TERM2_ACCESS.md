# Ontario FRI Term 2 access and rights

The official Ontario catalogue and GeoHub route were rechecked on 2026-08-20. The catalogue API still names Open Government Licence – Ontario but contains exactly two resources, both `WEB` GeoHub explorer pages. Neither is a stable, downloadable Term 2 FRI artifact or a deterministic complete API.

The current authoritative GeoHub page says Term 2 is in production and to check back for updates. Its inventory-development card identifies a **Romeo Malette Forest pilot test, incomplete**. The linked public Web Map has only a 39-feature FMU boundary index and one Romeo Malette pilot boundary (FMU 930); it does not contain Term 2 stand polygons. The map description calls its packaged products draft consultation/product-development data whose attributes, algorithms and formats may change, and says a final structure/content will be published after consultation.

Two public pilot ZIP URLs are visible in the map metadata. Read-only `HEAD` checks established `354,025,569` bytes for `RMF_FRI_SampleSet.gdb.zip` and `1,103,374,586` bytes for `RMF_Predictors_20m_SampleSet.gdb.zip`. Neither was downloaded, so no checksum, archive integrity, schema or package CRS is claimed. These are one-FMU samples, not a complete Term 2 artifact. The public T1/FIMv2 packaged-products map remains a separate pre-Term-2 route (78 direct ZIP links with explicit filename vintages 2007–2016).

The page also contains a stale/inconsistent range label: its program-overview text says `2018–2027`, while the inventory card, catalogue and Web Map say `2018–2028`. No publisher version or as-of statement resolves that discrepancy. The catalogue advertises OGL Ontario, but exact-package reuse, attribution, final schema, CRS, feature count, version and checksum remain unconfirmed for a released Term 2 package.

No file was downloaded, staged, transformed, ingested, or promoted. The machine-checked route record is [`data/phase1-ontario-fri-term2-route-exhaustion.json`](../data/phase1-ontario-fri-term2-route-exhaustion.json), and its checker is [`scripts/check-phase1-ontario-fri-term2-route-exhaustion.mjs`](../scripts/check-phase1-ontario-fri-term2-route-exhaustion.mjs). The recorded request asks the ministry for a final package or deterministic export, complete FMU coverage, version/as-of date, bytes, checksum, schema, CRS, feature count, attribution and exact-package rights for retention, transformation and redistribution. It remains unsent. Both `on-fri` and `on-fri-term-2` remain access-blocked with zero evidence credit.
