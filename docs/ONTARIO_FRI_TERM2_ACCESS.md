# Ontario FRI Term 2 access and rights

The official Ontario catalogue was rechecked on 2026-08-14. It still names Open Government Licence – Ontario but contains exactly two resources, both `WEB` GeoHub explorer pages. Neither is a stable, downloadable Term 2 FRI artifact or a deterministic complete API.

The catalogue describes the products as draft consultation/product-development data that may change in attributes, algorithms and format. Existing official Forest Cover terms evidence also carries an Electronic Intellectual Property notice, so OGL–Ontario cannot be assumed to govern a released Term 2 package without written confirmation.

No file was downloaded, staged, transformed, ingested, or promoted. The recorded request asks the ministry for selected-FMU package details, version, checksum, attribution, and written rights for retention, transformation and redistribution. It is unsent.
