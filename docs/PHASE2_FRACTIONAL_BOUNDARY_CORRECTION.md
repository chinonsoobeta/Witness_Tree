# Phase 2 fractional boundary correction (local only)

`scripts/phase2_annual_zonal_fractional_correction.py` is an isolated
post-processing path for the historical, nonproduction annual zonal output
from `scripts/phase2_annual_zonal_aggregate.py`. The historical worker is not
edited: its bytes and hash remain the baseline binding.

The correction worker requires the historical output and sidecar, the exact
38 forest-mask/annual-loss pairs (preferably through the same input manifest),
and the exact boundary file. It fails closed when any recorded path, byte
length, SHA-256, schedule, CRS, grid, nodata value, boundary source CRS,
boundary read policy, or target feature set differs.

For each target feature it creates two finite, temporary masks on the input
grid: the default GDAL polygon mask (the historical cell-centre membership)
and an `ALL_TOUCHED` mask of the polygon boundary. It divides those extents
into square 1,024-cell tiles by default (1,024–2,048 is enforced), clips the
province geometry to each tile, and intersects only boundary candidates with
exact cell geometry in the raster CRS. A process pool runs independent tiles
across the available logical CPU cores. Each tile reads at most its bounded
share of the 38 forest and 38 loss rasters instead of materializing all 76
arrays across a province-wide strip.

Tile workers never mutate shared totals. The parent writes per-target window
checkpoints and reduces completed tile aggregates in stable target/row/column
order with `math.fsum`, so worker scheduling cannot change the result. A
checkpoint binds the worker hash, exact historical output and sidecar, all
raster descriptors, boundary bytes and WKB hashes, target set, and tile size.
Resume fails closed if that binding changes. Progress is printed after each
checkpoint interval. For each category the reduction subtracts the binary
centre-membership contribution and adds the exact intersection fraction.
Cells entirely inside or outside the boundary therefore retain the binary
baseline; holes and grid-edge cells are handled by the same polygon
intersection operation. Unknown (`255`) remains a weighted unknown area and
keeps complete loss totals/rates null.

Both corrected JSON and its sidecar are write-once. The sidecar records the
historical baseline bindings, exact input bindings, source/working geometry
WKB hashes, candidate/fractional/full/zero/changed counts, parameters,
environment, and explicit limitations. It always declares `admitted: false`,
`released: false`, and `productionEligible: false`.

The real-data form is:

```sh
python3 scripts/phase2_annual_zonal_fractional_correction.py \
  --binary-output /path/to/annual.json \
  --binary-sidecar /path/to/annual.provenance.json \
  --forest-mask-dir /path/to/masks \
  --annual-loss-dir /path/to/loss \
  --boundaries /path/to/boundaries \
  --output /path/to/corrected.json \
  --sidecar /path/to/corrected.provenance.json \
  --checkpoint-dir /path/to/durable-checkpoints \
  --tile-size 1024
```

`--workers` defaults to all logical CPU cores, capped by the number of pending
tiles. `--checkpoint-interval` defaults to 16 candidate results per target.
Changing worker count or checkpoint cadence does not change the run binding;
changing exact inputs, code, geometry, or tile size does.

## Fixture verification

The small fixture is generated by
`tests/fixtures/phase2-annual-zonal-fractional-correction-fixture.py`. It
contains fractional BC/QC edges, a hole in AB, full ON cells, zero-area edge
candidates, and a BC Unknown cell. Its `--wide` mode crosses a 1,024-cell tile
boundary and proves byte-identical output across serial/parallel execution,
checkpoint resume, and checkpoint tamper detection. Run the focused test and
checker with:

```sh
node --test tests/phase2-annual-zonal-fractional-correction.test.mjs
npx eslint scripts/check-phase2-annual-zonal-fractional-correction.mjs tests/phase2-annual-zonal-fractional-correction.test.mjs
python3 -m py_compile scripts/phase2_annual_zonal_fractional_correction.py tests/fixtures/phase2-annual-zonal-fractional-correction-fixture.py
```

The checker is structural and read-only. It verifies the final output,
sidecar, worker, and target checkpoint bytes, but it does not reopen external
rasters or independently recompute intersections. The worker's input readback
is the fail-closed boundary. Fixture success is not a formal Phase 2 gate and
does not authorize admission or release.
