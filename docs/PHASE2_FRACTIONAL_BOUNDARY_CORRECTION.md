# Phase 2 fractional boundary correction (local only)

`scripts/phase2_annual_zonal_fractional_correction.py` is an isolated
post-processing path for the historical, nonproduction annual zonal output
from `scripts/phase2_annual_zonal_aggregate.py`. The historical worker is not
edited: its bytes and hash remain the baseline binding.

The correction worker requires the historical output and sidecar, the exact
38 forest-mask/annual-loss pairs (preferably through the same input manifest),
and the exact boundary file. It fails closed when any recorded path, byte
length, SHA-256, schedule, CRS, grid, nodata value, boundary source CRS,
boundary read policy, or target feature set differs.

For each target feature it creates two finite, temporary masks on the input
grid: the default GDAL polygon mask (the historical cell-centre membership)
and an `ALL_TOUCHED` mask of the polygon boundary. It intersects only boundary
candidate cells with the exact polygon cell geometry in the raster CRS. For
each category it subtracts the binary centre-membership contribution and adds
the exact intersection fraction. Cells entirely inside or outside the
boundary therefore retain the binary baseline; holes and grid-edge cells are
handled by the same polygon intersection operation. Unknown (`255`) remains a
weighted unknown area and keeps complete loss totals/rates null.

Both corrected JSON and its sidecar are write-once. The sidecar records the
historical baseline bindings, exact input bindings, source/working geometry
WKB hashes, candidate/fractional/full/zero/changed counts, parameters,
environment, and explicit limitations. It always declares `admitted: false`,
`released: false`, and `productionEligible: false`.

## Fixture verification

The small fixture is generated by
`tests/fixtures/phase2-annual-zonal-fractional-correction-fixture.py`. It
contains fractional BC/QC edges, a hole in AB, full ON cells, zero-area edge
candidates, and a BC Unknown cell. Run the focused test and checker with:

```sh
node --test tests/phase2-annual-zonal-fractional-correction.test.mjs
npx eslint scripts/check-phase2-annual-zonal-fractional-correction.mjs tests/phase2-annual-zonal-fractional-correction.test.mjs
python3 -m py_compile scripts/phase2_annual_zonal_fractional_correction.py tests/fixtures/phase2-annual-zonal-fractional-correction-fixture.py
```

The checker is structural and read-only; it does not reopen external rasters
or independently recompute intersections. The worker's input readback is the
fail-closed boundary. This path is not a formal Phase 2 gate, does not run the
real 76-raster dataset, and does not authorize admission or release.
