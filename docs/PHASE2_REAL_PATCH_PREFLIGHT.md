# Phase 2 real patch-vectorization preflight

The next owner-independent real-data batch remains blocked before national execution. No national patch output was created. A read-only profile opened four fixed 1024 × 1024 windows from the checksum-bound 2021–2022 loss raster. The windows contained 30,548 loss cells and 5,546 four-connected components within their truncated window edges; the measured profile took 0.122261 seconds. Those observations are useful for implementation tests, but they cannot establish national component counts because patches can cross window boundaries and the other 37 year-pairs were not inventoried.

The executable event contract now fixes four-neighbour connectivity, sorted unique cell lineage, one unsimplified cell polygon per loss cell, 0.09 hectares per cell, stable checksum-derived event IDs, the approved method identity, the source loss-raster SHA-256, and `released: false` / `productionEligible: false`. A committed portable source map pins all 38 adjacent 1984–2022 year pairs to the exact SHA-256 values in the audited national lineage, so event construction has no dependency on an owner-specific output path. It rejects disconnected, duplicated, reordered, out-of-grid, out-of-range or non-adjacent years, arbitrary 64-hex digests, and a valid digest belonging to a different pair.

The portable profile validator uses an independent summary with pinned profile and loss-source-map digests. It exact-validates the profile object and the ordered four-window rows, including offsets, 1024 × 1024 dimensions, counts, the string-form elapsed observation `0.122261`, and the full limitation. Extras, reordering, duplication, offset/count drift, a 59-second substitution, or coordinated record/summary tampering fail closed. The local gate additionally re-runs the read-only profile and verifies the source raster and full 38-pair map against the audited lineage.

The next executor is now implemented but has not been run on a full real pair. It reads at most 64 raster rows at a time, limits GDAL's cache to 64 MiB, and carries only components touching the previous row. Components crossing a read-block boundary are therefore stitched with the same four-neighbour rule as components inside a block. It writes no scratch data and produces an exact loss-cell count, component count, nodata count, and SHA-256 over every ordered loss run. Before the all-pairs loop writes anything, it verifies all 38 canonical input names, non-symlink file types and SHA-256 values and all 38 final and partial output names. The real mode rejects a non-canonical year pair or raster checksum and enforces a 96-hour deadline.

When requested, the executor writes an append-only, checksum-bound JSONL stream of inclusive row runs, stable component aliases, finalized component counts, and a non-production footer. Each stream is written under a `.partial` suffix, flushed and fsynced, then atomically hard-linked to its final unused name; timeout, byte-cap failure or another exception can therefore leave only a clearly partial file, never a final-named incomplete stream. The all-pairs mode shares one 2 TiB retained-lineage budget across the 38 pair streams and stops before exceeding it. Synthetic tests prove identical results for one-row and multi-row blocks, replayable aliases across a merge, exact fixture-value rejection before NumPy conversion, and fail-closed partial-file handling. They do not substitute for a real full-pair replay or measured output.

The fail-closed capacity result is deliberate. Across 38 pairs the grid has 945,810,357,120 cell positions. If every position were changed, the decimal cell-index arrays alone would require 10,927,502,063,298 canonical bytes, before geometry or event fields, exceeding the approved 2 TiB cap. That is an absolute contract bound, not an estimate of actual loss. The bounded sample cannot replace an exact all-pair loss-cell inventory, a full-pair stitcher replay with per-component lineage, or measured retained/scratch bytes and elapsed time. Until those three blockers close, the approved 8-vCPU, 16-GiB, 2-TiB, 96-hour national run must not start.
