# Third-party notices

## BC Sans

This project includes [@bcgov/bc-sans](https://github.com/bcgov/bc-sans) for the BC Sans web font. BC Sans is the standard font for B.C. Government digital services and is a modified version of Noto Sans with support for Indigenous languages in British Columbia.

The package is distributed under the SIL Open Font License 1.1. Its repository also includes Apache-2.0 licensing material for the package source. See the package's `LICENSE`, `LICENSE_OFL.txt`, and [README](https://github.com/bcgov/bc-sans) for the complete terms and notices.

## Province flag icons

The shared province bar includes compact inline SVG renditions based on the flags of [British Columbia](https://commons.wikimedia.org/wiki/File:Flag_of_British_Columbia.svg), [Alberta](https://commons.wikimedia.org/wiki/File:Flag_of_Alberta.svg), [Ontario](https://commons.wikimedia.org/wiki/File:Flag_of_Ontario.svg), and [Québec](https://commons.wikimedia.org/wiki/File:Flag_of_Quebec.svg). Each linked source page identifies its vector file as public domain. The renditions are embedded in the application and are not loaded from Wikimedia at runtime.
