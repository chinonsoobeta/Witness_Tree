## Read-only geospatial profile

The extracted working copies were profiled without modifying source geometry. The machine-checked summary is in [`data/staged-geospatial-profile.json`](../data/staged-geospatial-profile.json), and the reproducible read-only profiler is [`scripts/profile-staged-geospatial.py`](../scripts/profile-staged-geospatial.py).

- Québec contains 94,572 fire multipolygons and 94,572 metadata points in EPSG:32198. Neither layer has missing, empty, or invalid geometries. It is ready for transformation design, not ingestion or production.
- Alberta contains 788,810 AVI Crown features, 3,631 post-inventory harvest features, and two index features in EPSG:3400. Profiling found 608 ring self-intersections: 587 in `AVI_Crown`, 19 in `AVI_PostInventoryHarvest`, and one in each index layer.

That deterministic repair-or-quarantine rule has since been implemented, tested, and recorded. Over 792,443 features it left 791,835 unchanged, repaired 607 of the 608 invalid geometries, and quarantined 1. The largest relative area change across all accepted repairs is about 7.0e-14, so the repairs were topological rather than reshapes, and the run produced identical output when executed a second time. The single quarantined feature would have moved 2.88% of its area, so it is held out rather than rewritten. The run is recorded in `data/transformation-runs/alberta-avi-geometry-repair-v1-2026-08-12.json` and `docs/ALBERTA_GEOMETRY_REPAIR.md`. Alberta is admitted to transformation design only; it is not admitted to ingestion and is not production eligible. No source geometry was changed, and no invalid geometry was silently repaired or discarded.

The first Québec transformation is a lossless layer copy: no semantic, attribute, coordinate, or geometry change. Its two 94,572-feature layers retain matching input/output fingerprints and zero missing, empty, or invalid geometries. The 1,017,495,552-byte external GeoPackage has SHA-256 `7b0749f5a237f1abb3cf110c5748ed5cbdc8afa738beb021bba68a19927a24a8`; the checked-in summary is [`data/transformation-runs/qc-historic-wildfire-v1-2026-08-12.json`](../data/transformation-runs/qc-historic-wildfire-v1-2026-08-12.json). It is not ingested, immutable, or production eligible.
