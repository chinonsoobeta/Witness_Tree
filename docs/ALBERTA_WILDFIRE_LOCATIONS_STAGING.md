# Alberta current wildfire-locations staging

The plan row `ab-wildfire` is represented by one checksum-bound local snapshot of the official Government of Alberta `wildfire/alberta_fire_status/FeatureServer/0` **Alberta Wildfire Locations** layer. Alberta describes the parent service as the source for current-fire statistics; the layer contains current fire-year and carryover locations. It is a locations feed, not an assertion that all wildfire perimeters are available or that the snapshot is real-time.

The raw GeoJSON is outside Git at `Witness_Tree-data/raw/alberta-wildfire-locations/2026-08-14/alberta-wildfire-locations_2026-08-14.geojson`. It is 423,853 bytes with SHA-256 `f0e86ea34a7624c365349b3a8fbb77967bb45ab73c507cf441efb8f6a8736ee0`. The service declares a 1,000-record limit and the unpaged response contains 751 features, so no paging, filtering, or merge was used. Read-only GDAL and coordinate checks found EPSG:4326 Point features with zero missing, empty, malformed, or out-of-range geometries. No geometry was repaired.

The Alberta Open Data policy applies the Open Government Licence – Alberta to publicly available government data unless exempt. The official wildfire page points to this public Alberta Geospatial Services Platform service and the service publishes no different licence or attribution statement; its default attribution is recorded in the staged manifest. This is local staging only: not immutable storage, a real-time feed, transformed data, ingested data, or production output. A refresh must stage a separately dated response and repeat the count, checksum, profile, attribution, and retention checks.
