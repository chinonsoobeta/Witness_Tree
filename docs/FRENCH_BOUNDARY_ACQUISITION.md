# French boundary acquisition targets

[`data/french-boundary-acquisition-targets.json`](../data/french-boundary-acquisition-targets.json) records the authoritative catalogue targets needed for French FED, CD, and CSD boundary editions. Every target is `not-staged`, has no checksum or profile, and is not production eligible.

The French 2023 federal target is pinned to the Elections Canada catalogue's French SHP resource. The Statistics Canada CD and CSD targets deliberately retain no guessed file name: an authorized future acquisition must select the exact French artifact from the publisher's French boundary form, then record the resulting retrieval, checksum, profile, licence attribution, archive proof, and separate production admission.
