# Phase 2 synthetic event integration

This owner-independent batch proves the event-and-aggregation path without making a production claim. It combines the checksum-bound example forest masks and detected-change patches with checksum-bound synthetic fire, qualified recorded-harvest, insect/disease and other-intervention overlays. The overlay checksum binds its exact overlay ID and records. It uses the registered 50 percent spatial rule, temporal tolerances, stable candidate order and the complete five-kind precedence order. All matching candidates and precedence evidence remain available after a winner is selected.

Every official and detected event is normalized as `example`, `reviewStatus: unapproved` and `productionEligible: false`, with grid geometry, cell lineage, method identity, data version, boundary edition and source checksums. The executable matching, precedence, aggregation and boundary rules must match the exact checksum-bound method manifest. The canonical boundary-crosswalk content is hashed again and must equal the manifest value. The batch requires versioned boundaries covering province, watershed, forest district, municipality, provincial riding, federal riding, reserve and treaty area. Grid drift, missing geography types, duplicate intersections, unqualified harvest, checksum drift, non-continuous or out-of-range years and missing first-year denominators fail closed.

Time-range aggregates use forested hectares in the first requested year as their denominator. A hectare-year has exactly one precedence winner, while every overlapping record is retained in lineage. Winning and retained IDs resolve directly to emitted event IDs. Each aggregate carries checksum-bound hectare-year contributions with cell fractions; validation reconstructs its area from the mapped precedence evidence. A zero first-year denominator produces an explicit unknown rate rather than division by zero.

The existing baseline runner optionally accepts a synthetic overlay and inclusive year range. It persists integrated events, aggregates and precedence evidence beside the baseline files in a newly created write-once directory. The same lineage manifest records every output checksum plus overlay identity and range. Repeating the run against that directory fails rather than overwriting it.

`npm run readback:phase2-synthetic-output -- <output-directory>` is the persisted-output replay gate. It requires the exact declared seven-file inventory, recomputes every output checksum, parses all baseline and integration files, and reruns event references, precedence mappings, contribution arithmetic, first-year denominators, unique boundary/range identities and all-eight geography coverage. Deterministic helpers query an emitted event by ID, retrieve boundary/year lineage, and replay a boundary/range aggregate with a stable checksum. Missing, extra, altered, production-labelled or cross-file-inconsistent outputs fail closed.

This is synthetic grid-cell evidence only. It does not transform NTEMS, approve the unresolved forest crosswalk, ingest CA Forest Harvest or fire data, create a production event table, publish statistics, generate tiles, or close a Phase 2 exit criterion.
