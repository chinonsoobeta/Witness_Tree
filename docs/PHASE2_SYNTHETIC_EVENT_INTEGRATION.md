# Phase 2 synthetic event integration

This owner-independent batch proves the event-and-aggregation path without making a production claim. It combines the checksum-bound example forest masks and detected-change patches with checksum-bound synthetic fire and qualified recorded-harvest overlays. It uses the registered 50 percent spatial rule, temporal tolerances, stable candidate order and fire-first precedence. All matching candidates and precedence evidence remain available after a winner is selected.

Every official and detected event is normalized as `example`, `reviewStatus: unapproved` and `productionEligible: false`, with grid geometry, cell lineage, method identity, data version, boundary edition and source checksums. The executable matching, precedence, aggregation and boundary rules must match the exact checksum-bound method manifest. The batch requires versioned boundaries covering province, watershed, forest district, municipality, provincial riding, federal riding, reserve and treaty area. Grid drift, missing geography types, duplicate intersections, unqualified harvest, checksum drift and missing first-year denominators fail closed.

Time-range aggregates use forested hectares in the first requested year as their denominator. A hectare-year has exactly one precedence winner, while every overlapping record is retained in lineage. A zero first-year denominator produces an explicit unknown rate rather than division by zero.

This is synthetic grid-cell evidence only. It does not transform NTEMS, approve the unresolved forest crosswalk, ingest CA Forest Harvest or fire data, create a production event table, publish statistics, generate tiles, or close a Phase 2 exit criterion.
