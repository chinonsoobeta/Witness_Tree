# Federal-electoral output verification

scripts/check-phase1-federal-electoral-output.mjs is an independent,
read-only verifier for the completed federal-electoral-districts-2023-v1
artifact. It does not update the GeoPackage, sidecar, source files,
specification, packet, ledger, or execution authorization.

Run the default check with:

    npm run check:phase1-federal-electoral-output

The verifier checks the canonical output and sidecar hashes, canonical sidecar
JSON, exact schema and layer, 352 Polygon features, 343 distinct FED_NUM
values, REPORDER=2023, NAD83 Lambert CRS, zero missing/empty/invalid
geometries, exact source geometry readback, and all lineage fields:
source_fid, output_record_id, source_raw_sha256, and source_layer.

It then runs the same ogr2ogr selection and lineage update in a newly created
private temporary directory, applies the fixed GeoPackage timestamp
2000-01-01T00:00:00.000Z, and compares the regenerated bytes and SHA-256 to
the canonical output. The temporary directory is removed in a finally block;
its path is never recorded as evidence.

The verifier emits no repository file by default. To write the truthful,
non-admitting readback record, explicitly pass:

    node scripts/check-phase1-federal-electoral-output.mjs --write-evidence

That creates
data/phase1-federal-electoral-output-verification-evidence.json with
canonical JSON and refuses to overwrite an existing evidence file. The record
claims verification only; ingestion, release, production admission,
production eligibility, deployment, and external mutation remain false.
