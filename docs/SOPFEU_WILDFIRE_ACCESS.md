# SOPFEU wildfire source access

SOPFEU’s public site presents current wildfire information, but no official versioned bulk snapshot, documented open data/API contract, or refresh cadence was found. The observed API base is not a published data contract: the base and common documentation paths did not expose API documentation.

The SOPFEU terms state that reproduction, distribution, or modification needs prior written authorization. They are not an open-data licence and do not authorize internal immutable archival, transformation, derived/public redistribution, or scheduled refresh.

The separate MRNF historical `Feux de forêt` CC BY source is not SOPFEU data and cannot supply SOPFEU reuse rights. No SOPFEU data was downloaded, staged, transformed, ingested, or promoted. The bilingual permission request was sent to `courrier@sopfeu.qc.ca`; [`data/phase1-permission-outreach-package.json`](../data/phase1-permission-outreach-package.json) records it as verified sent at 2026-08-14T18:52:14-05:00. The reply audit of 2026-08-21 in [`data/phase1-outreach-reply-audit.json`](../data/phase1-outreach-reply-audit.json) records no substantive reply, and a read-only mailbox check on 2026-09-13 found none either. The draft text kept in `data/sopfeu-wildfire-access-block.json` still says it has not been sent because it predates sending. SOPFEU therefore stays excluded from the scheduled wildfire archive. The request asks for the exact rights, endpoint, snapshot/version, cadence, attribution, correction, archive, transformation, and public-redistribution conditions needed before any acquisition.
